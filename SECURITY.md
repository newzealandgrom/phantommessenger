# Security Policy / Политика безопасности

## Сообщить об уязвимости / Reporting a vulnerability

RU: Пишите на **admin@phantommessenger.org**. Не создавайте публичные issue для уязвимостей.
Укажите версию (`selfhost/VERSION`), шаги воспроизведения и влияние. Мы подтвердим получение и сообщим о сроках исправления.

EN: Email **admin@phantommessenger.org**. Please do not open public issues for vulnerabilities.
Include the version (`selfhost/VERSION`), reproduction steps and impact. We will acknowledge receipt and share a fix timeline.
